# N'djar Design System Foundation

## Source

The visual base comes from `ndjar_app_prototipos_frontend.png`, the local brand guide and ui-ux-pro-max recommendations.

## Direction

Use a practical agricultural product UI. The mobile app must feel operational and trustworthy, not decorative.

The public web can use stronger app-store style presentation, screenshots and download calls to action after the mobile MVP exists.

## Typography

Use Inter as the main cross-platform font. On Android, Roboto fallback is acceptable. The web can test Calistoga for selected public marketing headings only, but not inside dense app screens.

- Region card.
- Crop card.
- Doctor card.
- Consultation card.
- Forum question card.
- Library resource item.
- Bottom tab item.

## Accessibility Rules

Each state needs text plus colour.

Touch targets must be at least 44 px.

Critical information must be visible without hover.

The app must work on small Android screens.
