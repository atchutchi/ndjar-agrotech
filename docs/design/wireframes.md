# N'djar Wireframes

## Mobile App

The MVP follows the 24 prototype screens.

Splash introduces N'djar and offline or USSD support.

Onboarding explains decisions with data.

Language lets the user choose Portuguese first, with Crioulo, Fula and Balanta planned.

Home shows region status, pH, alerts and shortcuts.

Map lets the user select pilot zones and see pH status.

Region detail explains the selected zone and next action.

Crop list shows recommended crops by region.

Crop detail shows pH ideal, compatibility and cultivation notes.

Calendar shows seasonal tasks.

Sample form stores a draft with community, parcel, coordinates and photo.

Doctor list shows consultants and availability.

Consultation request captures topic, urgency, crop and notes.

Chat shows safe assistant answer or human escalation.

Forum supports questions but requires moderation.

Library stores guides for offline reading.

Profile shows parcels, samples, alerts, language and sync.

## Web

The public web starts with N'djar value proposition, pilot, services, screenshots and contact.

The admin web starts with management tables for regions, crops, calendar, library, consultations and forum moderation.
