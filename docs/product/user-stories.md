# N'djar User Stories

## Farmer

As a farmer, I want to use the app in Portuguese first and later in local languages so that I can understand the guidance.

As a farmer, I want to see my pilot region and pH context so that I know which crops may be suitable.

As a farmer, I want to register a soil sample with parcel, community, crop and photo so that a technician can validate it later.

As a farmer, I want to read agricultural guides offline so that lack of internet does not block field work.

As a farmer, I want to ask a question and get a safe answer or escalation so that I do not act on uncertain advice.

## Agricultural Doctor

As an agricultural doctor, I want to receive questions that the robot cannot answer safely so that I can give a human opinion.

As an agricultural doctor, I want to respond within 24 hours so that farmers know when to expect help.

As an agricultural doctor, I want to see region, crop, pH status and sample notes before responding so that my advice has context.

## Admin

As an admin, I want to manage crops, regions, pH ranges and sources so that the platform remains accurate.

As an admin, I want to approve assistant answers before they become reusable so that the robot does not invent guidance.

As an admin, I want to moderate forum posts so that harmful advice does not spread.

## Public Visitor

As a public visitor, I want to understand N'djar quickly so that I can decide whether to contact or partner with the project.

As a funder, I want to see strategy, pilot area and future roadmap so that I can evaluate the project.
